# Race Control screen — beta

Authorized Race Control sees:
- large RACE # / STAGING / GET READY cards
- class name under each race number
- one large ADVANCE button
- manual SET/CORRECT control
- race program list beneath
- SKIP control for a cancelled/skipped race
- last update time

Everyone else only sees the compact persistent three-column bar.

Advance behavior should use the race program order when available, so skipped/reordered races do not force sequential numbering.
